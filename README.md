### [WoW 3.3.5a Italiano](https://github.com/Spirax-M1/WoW-3.3.5a-Italiano)

Maintenance of an Italian localization package for World of Warcraft WotLK. Version 1.0.1 includes automated installer tests and a reproducible packaging script.

[Download and release notes](https://github.com/Spirax-M1/WoW-3.3.5a-Italiano/releases/latest)

### [Algorithmic trading research](https://github.com/Spirax-M1/algorithmic-trading-ml)

An ongoing reconstruction of earlier time-series ML experiments. The [draft research branch](https://github.com/Spirax-M1/algorithmic-trading-ml/pull/1) introduces an offline baseline, temporal validation, explicit costs and regression tests. Evaluation on the original MT5 datasets is pending; the project does not currently demonstrate predictive performance or trading profitability.
